- Prefers short answers; often asks "answer first" before any work.
- Wants to review each result (renders/screenshots) and give the go-ahead before the next step.
- Dislikes faceted/low-poly visuals (rejected the decimated chassis and the scanned dam); keep meshes full detail and smooth-shaded, use clean modelled geometry with good textures.
- Cares about using the GPU well (asked about moving from WSL to native Linux for smooth Gazebo).

**Why:** stated directly during the Phase 1 session (2026-10-16).
**How to apply:** answer briefly, show a render, stop and ask before continuing. See [[wcr-dam-sim-setup]].
